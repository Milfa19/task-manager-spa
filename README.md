# Task Manager SPA

Простое одностраничное приложение для управления задачами.

## 🚀 Функционал
- Добавление задач
- Фильтрация по стеку
- Удаление задач
- Сохранение в LocalStorage

## 🛠 Технологии
- HTML
- CSS
- JavaScript (Vanilla)

## ▶️ Запуск
Открыть index.html в браузере

## 💾 Данные
Сохраняются в LocalStorage
